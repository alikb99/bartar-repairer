# برنامه اقدام — bartar-repairer.com

مرتب شده بر اساس نسبت تاثیر به تلاش. امتیاز فعلی: ۷۶ از ۱۰۰.

## فاز ۰ — دیپلوی کار انجام شده (همین امروز)

کارهای امروز روی دیسک هستند ولی زنده نشده اند. تا دیپلوی نشوند هیچ اثری ندارند.

- [ ] کامیت و دیپلوی بلوک محتوای خوشه ای روی ۸ صفحه هدف
- [ ] دیپلوی ۱۴ عکس کارگاهی (۱٫۸ مگابایت)
- [ ] دیپلوی اصلاح تایتل و متای هایسنس و موتورولا

## فاز ۱ — بحرانی (هفته اول)

### ۱. کاهش TTFB
**تاثیر: بسیار بالا — روی هر ۸۹۳ صفحه**
TTFB فعلی ۱٫۰۴ تا ۱٫۱۱ ثانیه روی HTML استاتیک است. هدف زیر ۲۰۰ میلی ثانیه.

گزینه ها به ترتیب اولویت:
1. قرار دادن دامنه پشت CDN با نود داخل ایران (آروان کلاد یا ابر دراک).
2. اگر CDN ممکن نیست، انتقال به میزبانی با دیسک SSD و تنظیم `sendfile on; tcp_nopush on;` در nginx.
3. بررسی اینکه nginx فایل ها را از دیسک شبکه ای کند نمی خواند.

بدون این کار، LCP روی موبایل زیر ۲٫۵ ثانیه نمی رود، هرچقدر هم فرانت اند بهینه شود.

### ۲. افزودن هدرهای امنیتی
**تاثیر: بالا — تلاش: ۱۵ دقیقه**

در بلوک `server` کانفیگ nginx:
```nginx
add_header Strict-Transport-Security "max-age=63072000; includeSubDomains; preload" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "SAMEORIGIN" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
```

### ۳. اصلاح کش و فعال کردن Brotli
**تاثیر: بالا — تلاش: ۳۰ دقیقه**

```nginx
brotli on;
brotli_types text/html text/css application/javascript application/json image/svg+xml;
brotli_comp_level 5;

location /_next/static/ {
    add_header Cache-Control "public, max-age=31536000, immutable";
}
location / {
    add_header Cache-Control "public, max-age=600, stale-while-revalidate=86400";
}
```

## فاز ۲ — پرتاثیر (هفته دوم و سوم)

### ۴. افزودن alt به لوگوهای برند
**تاثیر: متوسط تا بالا — تلاش: ۱ ساعت**

حدود ۴۰ تصویر بدون alt، بیشتر در شبکه «برندهای قابل تعمیر». چون این تصاویر داخل HTML وردپرس هستند، بهترین راه یک اسکریپت روی `content/posts.json` است که با تطبیق نام فایل، alt فارسی تزریق کند:

| فایل | alt پیشنهادی |
|---|---|
| `samsung.webp` | تعمیر گوشی سامسونگ |
| `apple-1-150x150.webp` | تعمیر گوشی آیفون |
| `realme.webp` | تعمیر گوشی ریلمی |
| `oppo.webp` | تعمیر گوشی اوپو |
| `oneplus.webp` | تعمیر گوشی وان پلاس |
| `vivo.webp` | تعمیر گوشی ویوو |

### ۵. بازنویسی تایتل و متای صفحه تماس
**تاثیر: متوسط — تلاش: ۵ دقیقه**

تایتل فعلی «تماس» (۴ کاراکتر) به:
```
آدرس و شماره تماس تعمیرات برتر | شعبه مطهری و سعادت آباد
```
متا:
```
آدرس دو شعبه تعمیرات برتر در تهران، شماره تماس مستقیم هر شعبه و ساعت کاری. شعبه مرکزی خیابان مطهری و شعبه غرب سعادت آباد میدان کاج.
```

این صفحه برای «شماره تعمیرات موبایل»، «آدرس تعمیرگاه موبایل تهران» و «تعمیرات موبایل سعادت آباد» ظرفیت دارد که هر سه در فهرست ۴۳۸ کلمه هستند.

### ۶. حذف ایموji و تکرار در تایتل ها
**تاثیر: پایین تا متوسط — تلاش: ۱۰ دقیقه**

- `/nothingphone-repair/`: حذف ایموji موبایل.
- `/motorola-mobile-repair-center/`: حذف «نمایندگی» دوم. با احتیاط، چون این صفحه در جایگاه ۳ است.

### ۷. تقویت صفحه فهرست مقالات
**تاثیر: متوسط — تلاش: ۲ ساعت**

`/blog/` با ۶۷۹ کلمه و صفر H2. افزودن گروه بندی موضوعی با H2 (تعمیر موبایل، لپ تاپ، لوازم خانگی، راهنمای خرید) و یک پاراگراف معرفی برای هر گروه.

## فاز ۳ — محتوا و اقتدار (ماه دوم)

### ۸. جمع آوری نظرات واقعی مشتری
**تاثیر: بالا در دسته محلی**

`CUSTOMER_REVIEWS` در `lib/pricing.ts` عمداً خالی است و این تصمیم درستی بوده. با جمع آوری نظرات واقعی از مشتریان (فرم پس از تحویل یا نظرات Google Business Profile) می توان `aggregateRating` را فعال کرد. این تنها سیگنالی است که سایت کاملاً فاقد آن است و رقبا دارند.

### ۹. علامت گذاری قیمت با اسکیمای Offer
**تاثیر: متوسط**

جدول ۲۶۰ ردیفی قیمت را با `AggregateOffer` علامت گذاری کنید:
```json
{
  "@type": "Offer",
  "itemOffered": {"@type": "Service", "name": "تعویض باتری گلکسی A54"},
  "priceCurrency": "IRR",
  "priceSpecification": {
    "@type": "PriceSpecification",
    "minPrice": 3300000, "maxPrice": 5400000
  }
}
```

### ۱۰. معرفی تکنسین ها با هویت واقعی
**تاثیر: متوسط تا بالا برای E-E-A-T**

اسکیمای `Person` فعلی به یک هویت تحریریه کلی اشاره می کند. با ۹۳۶ عکس واقعی کارگاه در اختیار، ساختن صفحه «تیم فنی» با نام، سابقه و تخصص هر تکنسین کاملاً شدنی است.

### ۱۱. ادامه خوشه های باقی مانده
از ۴۳۸ کلمه، ۸ صفحه هدف پوشش داده شد. خوشه های بعدی به ترتیب ارزش: ایسر (۱۴۸ ایمپرشن)، MSI (۱۲۱)، ایسوس (۱۱۹)، هواوی (۱۱۰)، لنوو (۶۹)، ناتینگ فون (۴۴).

## انتظار واقع بینانه

بهبود فنی فاز ۱ روی همه صفحات اثر می گذارد و قابل اندازه گیری است. اما جایگاه ۱۷ برای «نمایندگی تعمیرات سامسونگ» عمدتاً مسئله اقتدار دامنه است نه محتوای صفحه. بدون داده بک لینک نمی توان گفت فاصله تا صفحه اول چقدر است. پیشنهاد می کنم پیش از سرمایه گذاری بیشتر روی این کلمه، پروفایل بک لینک بررسی شود.
